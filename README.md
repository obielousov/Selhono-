# Selhono — Interior Design Portfolio

A fully responsive multi-page website for an interior design studio, created as a frontend portfolio project. The website features a clean elegant interface, an interactive project catalog with filter tabs and pagination, a reviews slider, and a fully responsive user experience across all devices.

🌐 Live Demo: https://obielousov.github.io/Selhono-/

## Features

- **Interactive project catalog** — filter tabs (Bathroom, Bed Room, Kitchen, Living Area) with pagination
- **Multi-page layout** — 13 pages covering the full interior design portfolio flow
- **Pricing cards with active toggle** — services page
- **Swiper reviews slider** — responsive carousel with custom navigation
- **FAQ accordions** — spollers with smooth animation
- **Animated counters** — statistics on the home page
- **Responsive navigation** — sticky header with a mobile menu
- **Accessibility** — semantic HTML, ARIA attributes, keyboard navigation
- **SEO & Social** — Open Graph and Twitter Card metadata

## Tech Stack

- **HTML5** — semantic markup, 13 pages
- **SCSS** — BEM, modular architecture compiled into CSS
- **Vanilla JavaScript** — framework-free ES Modules
- **Vite** — optimized production build
- **PostHTML** — HTML templating (includes, conditional blocks)
- **Swiper** — reviews slider
- **Assets** — self-hosted fonts (Jost & DM Serif Display), SVG icons, WebP images

## Run Locally

Clone the repository:

```bash
git clone https://github.com/obielousov/Selhono-.git
```

Open `index.html` in any modern browser.

No installation or build process is required.
