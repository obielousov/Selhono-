# Selhono

A responsive multi-page website for an interior design portfolio, created as a frontend portfolio project. The website features a clean elegant interface, an interactive project catalog with filter tabs and pagination, a reviews slider, and a fully responsive user experience across all devices.

## Features

- Fully responsive layout;
- Semantic HTML5 markup;
- Accessibility support (aria-\*, keyboard navigation, focus states);
- Interactive project catalog with filter tabs and pagination;
- Pricing cards with active toggle;
- Swiper reviews slider;
- FAQ accordions (spollers);
- SEO-friendly meta tags and Open Graph support;
- Optimized production build with Vite.

## Tech Stack

- HTML5
- SCSS (BEM)
- Vanilla JavaScript (ES Modules)
- Vite
- Swiper

## Installation

Clone the repository:

git clone https://github.com/obielousov/Selhono-.git

Open index.html in any modern browser.

No installation or build process is required.
